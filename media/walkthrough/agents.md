# Talk to Claude

Your first Claude tab is already open, beside this page. Type a message at the bottom of it and press Enter; this step
is ticked once you've sent one.

A Claude tab is a real Claude Code session in an editor tab: it reads and edits your workspace, runs commands when
you allow it, and keeps its history across reloads.

- More tabs: **New Claude tab** or **New Codex tab** in the **Perch** view, or **Agents: New Claude Tab** in the
  Command Palette.
- Each tab's footer shows which backend it uses and the usage left.
- The **Perch** view in the activity bar lists your tabs and past sessions.

Claude Code needs a sign-in the first time: **Agents: Log in to Claude (subscription)**, or an API key.
