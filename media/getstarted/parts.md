Agentic Works is four parts in one extension: Agents (Claude Code and Codex), Teams, Jira & Confluence, and PRs. All start
switched on; a part you don't use simply stays signed out.

Each box here switches one part. Switching a part off takes its icons, views and commands away at once, and its steps
leave this page; switching it back on brings them back, with no reload. Agents may ask first, if tabs are open.

**All settings** opens Agentic Works' settings: the same switches, then each part's own settings. **Done** ticks this step,
and so does changing a switch.
