Type the email address you use at work, so the sign-ins {{title}} set up can fill it in for you. The box already ends in the
company's domain; type the part before it and press **Save**.

Saving ticks this step. The address stays on this computer, in Roost's own storage: Roost never logs it and sends it to
no one. It goes only to the tools {{title}} set up, when they open a sign-in window:

- **Get a key**, in the gateway step, gets it for its sign-in.
- **Connect your tools** passes it to the sign-ins it runs.
- The Jira form starts with it.

You still sign in yourself each time: the address only saves you typing it. Only an address ending in the company's
domain is accepted.

**Not Now** ticks the step with nothing saved; the sign-ins then ask for your address as they did before. You can
come back and save it, or change it, here at any time.
